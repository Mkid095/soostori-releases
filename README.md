# Soostori POS — Releases

This repository holds **release binaries only**.

Application source code lives in private repositories. Public release history
is mirrored here so that:

- the downloads page can link installers directly without exposing source, and
- the in-app auto-updater can fetch `latest.yml` without authenticating.

Nothing here is a source repository. Do not commit code.

| Platform | Tag pattern | Asset |
|---|---|---|
| Desktop (Windows) | `desktop-vX.Y.Z` | `Soostori.POS-Setup-X.Y.Z.exe` |
| Mobile (Android) | `mobile-vX.Y.Z` | `Soostori-POS-mobile-vX.Y.Z.apk` |
